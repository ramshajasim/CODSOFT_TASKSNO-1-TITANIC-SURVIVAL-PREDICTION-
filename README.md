# Titanic Survival Prediction

An end-to-end Machine Learning project that predicts whether a passenger on the **RMS Titanic** survived or not, using a **Random Forest** model served through an interactive **Streamlit** web app.

## Project Structure

```
TITANIC SURVIVAL PREDICTION/
├── Titanic-Dataset.csv      # Kaggle Titanic dataset (~891 passengers)
├── train_model.py           # Data cleaning + model training script
├── app.py                   # Streamlit web application
├── pages/
│   └── 1_Actual_Passengers.py  # Explorer: real survived/died records (with filters)
├── titanic_model.pkl        # Trained model (generated by train_model.py)
├── requirements.txt         # Python dependencies
└── README.md                # This file
```

**Features used:** Age, Gender (Sex), Ticket Class (Pclass), Fare, SibSp, Parch, Embarked.

**Pipeline:** missing-value imputation (median / most-frequent) → one-hot encoding → standard scaling → Random Forest classifier. The whole pipeline is saved in one `.pkl` file, so training and serving stay perfectly in sync.

## 1. Run Locally

### Prerequisites
- Python **3.9 – 3.13** installed ([python.org](https://www.python.org/downloads/))

### Steps

```bash
# 1. Open a terminal in this project folder
cd "E:\TITANIC SURVIVAL PREDICTION"

# 2. (Recommended) create a virtual environment
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate    # macOS / Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Train the model (creates titanic_model.pkl)
python train_model.py

# 5. Launch the web app
streamlit run app.py
```

The app opens automatically at **http://localhost:8501**.

### Two pages
1. **Titanic Survival Prediction** (home) — enter details, get a prediction.
2. **Actual Passengers** (sidebar → *Actual Passengers*) — the real dataset: every passenger's **actual** Survived/Died result, with filters by status, class, gender, and name search. Includes a downloadable CSV and survival charts.

To retrain with a custom CSV path:

```bash
python train_model.py path\to\your\titanic.csv
```

## 2. Deploy FREE on Streamlit Community Cloud

1. Push this folder to a **GitHub repository** (keep `train_model.py` so the model can be retrained in the cloud, and commit `titanic_model.pkl` if you want it pre-trained).
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **"New app"** → select your repo, branch (`main`), and **`app.py`** as the main file.
4. Click **"Deploy"**. Your app will be live at `https://<your-app-name>.streamlit.app` in ~1 minute.

> **Tip:** Streamlit Cloud builds from `requirements.txt` automatically. The model file must exist in the repo (commit `titanic_model.pkl`) or be trained at build time.

## 4. How It Works

| Step | What happens |
|------|--------------|
| Load | `pandas` reads the Kaggle CSV |
| Clean | Keeps 7 features + target, fixes categoricals, drops duplicates |
| Impute | Missing `Age`/`Fare` → median; missing `Embarked` → most frequent |
| Encode | `Sex` & `Embarked` & `Pclass` → one-hot vectors; numeric features → standard scaled |
| Train | `RandomForestClassifier` (300 trees) with an 80/20 stratified split |
| Evaluate | Accuracy, F1, confusion matrix, classification report printed |
| Serve | `joblib` pipeline saved → Streamlit loads it and predicts instantly |

## Dataset

[Kaggle - Titanic Dataset](https://www.kaggle.com/datasets/yasserh/titanic-dataset) — 891 rows with passenger demographics and survival labels.
